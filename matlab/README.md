# 旁瓣抑制 SVA V0.1

## 运行
在项目根目录 MATLAB 命令窗口执行：
```matlab
addpath('matlab/sidelobe_v01');
run_sidelobe_v01;
```
也可传入输出目录：`run_sidelobe_v01('D:/your_output')`。
仅依赖 MATLAB 基础功能；CPU 运行，无需模型权重。

## 实现
复数联合 I/Q 权重，按距离、方位顺序处理。邻域和 s=x(n-k)+x(n+k)，
w=clip(-real(x*conj(s))/abs(s)^2,0,0.5)，y=x+w*s。
零分母取 w=0；每维边缘 k 个像素在该维处理时保持不变。
这是一种顺序可分离 SVA，不是 RSVA，也不保证保持所有目标相位。
依据：Stankwitz 等 SVA 思路及复数联合最小化；整数过采样前提见
https://pubmed.ncbi.nlm.nih.gov/18345138/ 。
复数二次目标的约束最小值可直接解析求得；脚本包含最小化数值检查。

## 数据与轴
受控仿真为解析二维 sinc 点扩散函数（非完整 RD 仿真），过采样率两轴均为2。
同时包含一个相隔约28像素的十分之一幅度弱目标。
实际 ROI 加载后作非共轭转置，统一为行=距离、列=方位；结果 MAT 也用此方向。
来源 `matlab/read_slc.m` 的原始 ROI 为行=方位、列=距离。
真实 ROI 默认 lag=[1,1]，仅探索性展示：已有处理窗、有效带宽和频谱中心未核实。
非整数过采样、非零频谱中心需重采样或广义 SVA，不能将本结果当成真实数据性能验收。

## 同尺度对照
原图、Hamming、SVA 共用输入最大幅度，图像显示 -60 至 +5 dB。
剖面共用原始目标剖面的峰值，禁止各输出自行归一化。
Hamming 采用单位相干增益的余弦基座窗，其空间域卷积核为
[0.23/0.54,1,0.23/0.54]，邻居间隔为 lag；不做处理后峰值再缩放。
真实数据中该窗与 SVA 同样依赖有效带宽假设。

## 评测口径
每个方向取原图峰值附近固定窗口；仿真窗口为±48像素，真实数据±32像素。
固定原图首零点/首局部极小值作为主瓣区间，所有方法共用；零点样本计入主瓣。
PSLR=20log10(旁瓣最大幅度/主瓣最大幅度)，ISLR=10log10(旁瓣能量/主瓣能量)。
因此 Hamming 的固定门 ISLR 包括展宽后溢出原主瓣门的能量，不能与使用各方法自身零点的文献值直接比较。
-3dB 宽度使用幅度1/sqrt(2)交点线性插值，单位像素；未核对物理间隔，不输出米。
峰值保持率、主瓣能量保持率分别相对于原图同一剖面门。
相位 RMSE 在输入幅度超过峰值10%且输出非零区域计算，相对输入，不是相位真值误差。
耗时是一次CPU算法调用，无预热统计，仅供参考，不是性能基准。
真实场景的邻近地物可能是真目标，其 PSLR/ISLR 仅是局部剖面代理指标。

## 交付
每个场景导出：复数 original/sva/hamming MAT、同尺度对比PNG、双方向剖面PNG。
总表 `traditional_comparison_v01.csv`；配置及检查结果 `parameters_v01.json`。
运行检查：全零输入、幅度/全局相位等变性、逐像素不增幅、单步权重最小化。
