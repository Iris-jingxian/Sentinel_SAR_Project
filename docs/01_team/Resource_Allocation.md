## 🎯 二、 详细任务与算力分配

### 👑 朱静娴（RTX 4060 8GB）—— 组长与集成负责人
*   **算力使用**：本地训练、代码联调。
*   **算法任务**：
    1.  完成 L0 数据解码、RD 成像、SLC 数据读取与参数提取（已完成）。
    2.  实现传统 PGA（相位梯度自聚焦）算法，作为自聚焦网络的对比基准。
    3.  **机动算力**：负责将廖智慧（自聚焦）与郭涵卓（旁瓣抑制）训练好的网络串联起来进行端到端测试。
    4.  负责最终的 Streamlit 界面开发与系统集成。

### 🎮 廖智慧（RTX 4070 8GB）—— 自聚焦负责人
*   **算力使用**：本地 GPU 主力训练。
*   **算法任务**：
    1.  负责搭建并训练深度学习自聚焦网络（PAFnet 或 RAFnet）。
    2.  使用切好的真实 SLC ROI 数据（`data/ROIs/`），注入相位误差构造散焦样本进行训练与验证。
    3.  将训练好的模型权重（`.pth`）提供给组长进行集成。
    4.  协助组长完成后续的 GUI 界面开发。

### 🎮 郭涵卓（RTX 4060 8GB）—— 旁瓣抑制负责人（深度学习）
*   **算力使用**：本地 GPU 主力训练。
*   **算法任务**：
    1.  负责搭建并训练深度学习旁瓣抑制网络（SVNN 或 CNN+RSVA）。
    2.  重点使用 `ROI_1_complex.mat`（强目标区）进行训练与推理测试，验证旁瓣抑制效果。
    3.  将训练好的模型权重导出，供组长集成。

### 💻 林嘉欣（Intel UHD 核显）—— 旁瓣抑制负责人（传统与评估）
*   **算力使用**：纯 CPU 运算与 MATLAB 脚本。
*   **算法任务**：
    1.  **传统算法**：使用 MATLAB 实现 SVA（空间变迹）旁瓣抑制算法。
    2.  **指标计算**：编写评估脚本，计算网络输出与 SVA 结果的距离向/方位向 PSLR（峰值旁瓣比）、ISLR（积分旁瓣比）及主瓣宽度。
    3.  **测试与对比**：负责在小尺寸的 512x512 数据集上，使用 CPU 跑网络推理（无需训练），并整理《传统与网络方法对比结果表》。

## ⚙️ 三、 协作规范与注意事项

1. **环境统一**：全员务必按照 `docs/Environment_Setup.md` 中的要求配置环境。MATLAB 需安装 Signal Processing Toolbox。
2. **PyTorch 安装**：三位有 N 卡的同学，在安装 PyTorch 时务必选择 **CUDA 11.8** 或 **12.1** 的版本，以发挥显卡加速效果。
3. **代码提交**：所有人编写的代码需按模块提交至 GitHub 对应目录（`matlab/` 或 `python/`），禁止直接上传大量数据集。
4. **算力互助**：如果林嘉欣在跑传统算法或评估脚本时遇到内存不足，可随时将数据转移给有显卡的同学协助运行。
