# B-11 旁瓣网络：结构与使用说明

## 网络结构

采用 CNN＋RSVA 路线中的 SCNN 网络分支，结构依据公开专利 CN110333489A 正文。输入为50点一维幅度窗口，预测窗口中心的主瓣参考幅度。

| 层 | 参数 | 输出形状 |
|---|---|---|
| 输入 | 单通道、窗长50 | B×1×50 |
| 卷积1＋ReLU | 核30，通道1→10 | B×10×50 |
| 卷积2＋ReLU | 核20，通道10→10 | B×10×50 |
| 卷积3＋ReLU | 核15，通道10→10 | B×10×50 |
| 卷积4＋ReLU | 核5，通道10→3 | B×3×50 |
| 展平＋全连接＋ReLU＋Dropout | 150→100，Dropout=0.1 | B×100 |
| 输出全连接 | 100→1 | B×1 |

共19,184个可训练参数。卷积步长均为1，补零保持长度，不使用池化。偶数卷积核左侧补(k−1)//2点，剩余补至右侧。输出为线性标量，允许标签超过输入峰值；保存原始预测，推理另提供截去负值后的幅度。

网络外部沿用幅值上限1000的滑窗规范化，内部输入除以1000、输出乘1000。每个窗口的标签与输入共用输入峰值尺度，预测后按保存的尺度还原。

## 数据与训练

沿用固定的30个仿真场景：训练18、验证6、测试6。分别产生17,424、5,808、5,808个窗口；同一场景的两个方向和全部窗口保持在同一集合。

采用Adam，学习率0.001、权重衰减0.00001、批大小256、随机种子77，训练20轮。上述训练参数为项目配置。损失为非零标签窗口与零标签窗口的MSE分别取平均后等权组合，计算时除去1000尺度；同时报告普通MSE，避免背景数量掩盖主瓣误差。按验证集平衡MSE选取第19轮权重，模型选择结束后评估测试集。

## 运行

实测环境：Python 3.13、PyTorch 2.8.0+cpu。安装 `python/B11_SCNN训练依赖.txt` 中的依赖。在项目根目录运行：

```powershell
# 检查网络与数据接口
python python/B11_SCNN网络验收.py

# 使用随附权重，对一个样本文件推理
python python/B11_SCNN窗口推理.py --input data/B11_SCNN滑窗样例/B11_test_000_SCNN滑窗.npz

# 复算分类结果与逐层数值梯度
python python/B11_SCNN结果复核.py

# 重新训练，另存一轮实验
python python/B11_SCNN训练.py --device cpu --output results/B11_SCNN复现
```

训练默认写入独立的复现目录；若该目录已有文件，需另指定空目录，以免覆盖实验记录。

权重为 `weights/B11_SCNN.pth`。推理返回各窗口中心的幅度、轴向、剖面索引和中心坐标，导出NPZ与MAT，不将分散中心点当成完整影像。

## 验收结果

- 固定64个训练窗口过拟合600步：损失由0.16655189降至0.00000665，下降99.996%。
- 随附权重的12个参数张量梯度均有限且非零；各选一个最大绝对梯度元素做双精度中心差分，最大相对误差1.45×10⁻⁹以内。此项为逐张量抽查，不是19,184个参数逐个差分。
- 8项网络与接口检查通过，权重保存／重载输出一致。
- 20轮最小训练记录见 `results/B11_SCNN训练/B11_训练日志.csv`。

| 测试方法 | 普通MSE | 非零标签MSE | 零标签MSE | 平衡MSE |
|---|---:|---:|---:|---:|
| SCNN | 0.013262 | 0.033589 | 0.010955 | 0.022272 |
| 原样输出中心值 | 0.380378 | 0.093698 | 0.412915 | 0.253307 |
| 全零输出 | 0.027460 | 0.269407 | 0 | 0.134703 |

测试共5,808个窗口，其中592个标签非零。本轮预测未出现负值，因此原始预测与截零后的指标相同。结果支持小规模仿真窗口回归可用；完整CNN＋RSVA还需接入真正RSVA支路，真实ROI的带宽、采样适配和整图效果另行验证。

按场景分组后，平衡MSE如下；每类包含2个独立仿真场景、1,936个窗口，详见 `B11_分类场景对照.csv`。

| 场景 | SCNN | 原样输出中心值 | 全零输出 |
|---|---:|---:|---:|
| 单点 | 0.022078 | 0.223073 | 0.178484 |
| 多点 | 0.019454 | 0.267474 | 0.114420 |
| 强弱目标邻近 | 0.022825 | 0.238731 | 0.150267 |

单点场景的非零标签MSE为0.026368，略高于原样输出的0.023968，说明主瓣幅度仍有失真。该类场景背景占比较高，全零输出的普通MSE反而低于SCNN，因此不能仅用普通MSE判断网络是否有效。强弱邻近场景的统计也不等同于弱目标检出率，后续需在完整剖面中核对弱目标峰值和位置。当前按三类场景报告结果，不用测试集调整训练参数。

后续正式训练先在训练／验证集比较主瓣保真损失及其权重，再接入RSVA支路，统一评价PSLR、ISLR、主瓣宽度和峰值保持率。本轮B-11保留网络搭建、小样本训练、梯度检查和权重推理的可复现实验。
