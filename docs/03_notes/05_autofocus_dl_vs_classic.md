# 第五周：SAR自聚焦端到端训练与传统算法对比

## 1. 本周目标与交付物
- **正式训练**：完成模型训练，保存验证曲线与首轮权重。
- **传统对比**：将深度学习模型（端到端/物理先验）与经典方法（相位梯度法、最小熵法）进行定量对比。
- **核心产出**：定位神经网络在跨场景任务中失败的原因，并给出解决方案。

**交付文件：**
- 权重文件：`model_best_epoch1.pth`（首轮）、`model_best.pth`（最佳）
- 训练曲线：`model_best_curve.png`
- 评估数据：`evaluation_results.csv`（端到端模型逐样本结果）

---

## 2. 实验设置与数据处理
- **场景划分**：严格遵循场景级不重叠（Train = ROI_2, Val = ROI_3, Test = ROI_1）。
- **标签与输入**：输入为散焦复图像的 [实部, 虚部] 或物理特征；标签为 6 阶多项式相位误差系数（重点监督主导的二次项 \(\alpha_2\)）。
- **MATLAB 基准**：基于最小熵准则生成的传统自聚焦基线。

---

## 3. 网络演进与核心诊断（问题清单）

在正式训练中，端到端 RAFnet 经历了严重的性能崩塌与修复过程，我们梳理了以下核心问题清单：

| 问题现象 | 根本原因 | 解决/验证方案 | 最终效果 |
| :--- | :--- | :--- | :--- |
| **模型塌缩（预测常数）** | 激活函数 `LeakyReLU(0.01)` 层层截断负半轴，Head 中的 `BatchNorm` 抹除了方位向不对称的符号信息。 | 移除 Head 中的 BN，将最后的激活替换为 `Tanh`。 | 验证集符号命中率 `sign` 从 **55% (随机)** 跃升至 **90%+**。 |
| **幅值塌缩（过度保守）** | 纯标准化 MSE 损失导致模型只敢预测接近均值的小幅值。 | 引入 `--aux-alpha-weight` 原始量级辅助损失，强行拉回幅值。 | 验证集 `val_corr` 达到 **0.80**，但测试集仍存在瓶颈。 |
| **跨场景泛化崩溃** | 原始频谱 `[real, imag]` 包含了场景自身纹理。CNN 走捷径记住了训练集纹理（Test Corr 仅 **0.64**），强散焦下发生符号翻转。 | 放弃端到端，提取**场景不变特征**（谱相关斜率）。 | 设计了 **PhaseGradNet**。 |

## 4. 传统对比结果（Test Set = ROI_1）

下表汇总了所有方法在测试集（未参与训练的新场景）上的相关系数（与干净图像对比）：

| 方法 (Method) | Test Corr (总体) | 备注 (Note) |
| :--- | :--- | :--- |
| 散焦原图 (Baseline) | 0.657 | 不进行任何补偿 |
| **RAFnet (原始谱输入)** | **0.64 ~ 0.66** | ❌ 负结果，发生严重纹理过拟合 |
| 经典相位梯度法 (Classical) | 0.857 | 传统解析解 |
| **PhaseGradNet (本文提出的DL救星)** | **0.860** | ✅ 成功追平经典法，证明了物理先验注入的有效性 |
| 最小熵自聚焦 (Min-Entropy) | 0.977 | 当前任务的理论上限（不依赖多项式相位假设） |
| 真值补偿 (Oracle) | 0.976 | 理想二次项补偿天花板 |

---

## 5. 结论与下一步
1. **端到端深度学习存在极限**：直接输入原始图像复频谱，模型会陷入“纹理捷径”，无法跨场景泛化。
2. **物理先验是破局关键**：将高维且充满噪声的原始频谱降维为 1 维相位梯度斜率（场景不变特征）后，CNN 成功学会了相位补偿映射，性能追平传统算法。
3. **DL 的上限**：受限于多项式相位模型，DL 无法超越解析法（0.86 vs 0.857），且两者均输给不依赖多项式假设的最小熵法（0.977）。
4. **下一步**：完善 PhaseGradNet 的代码结构，准备整合至主干代码库，并整理最终的终期文档。
