# 第1周学习笔记：复数、FFT与张量基础

> 本笔记面向B组全体成员，旨在快速建立SAR图像处理与深度学习所需的数学与编程基础，理解它们在“成像、自聚焦、旁瓣抑制”三模块中的具体作用。

## 一、 复数 (Complex Numbers)

### 1. 基础概念
在实数之外，引入虚数单位 \(j\)（工程中常用 \(j\)，数学中常用 \(i\)），满足 \(j^2 = -1\)。
复数可以表示为：
- **直角坐标形式**：\(z = a + bj\) （\(a\)为实部，\(b\)为虚部）
- **极坐标形式**：\(z = A e^{j\phi}\) （\(A\)为幅度，\(\phi\)为相位）

**欧拉公式**：\(e^{j\phi} = \cos\phi + j\sin\phi\)，它是连接三角函数与复指数的桥梁。

### 2. 在SAR项目中的应用
- **I/Q数据**：真实雷达接收到的信号是实数，但通过正交解调，我们会将其表示为复数（I为实部，Q为虚部）。这就是Sentinel-1 SLC数据是复数格式的原因。
- **相位的作用**：SAR图像不仅看幅度（目标亮暗），更要看相位。自聚焦（Autofocus）的本质就是估计并补偿相位误差；干涉SAR（InSAR）更是完全依赖相位差。
- **重要性**：在后续PyTorch网络中，复数必须被妥善处理（例如拆成两个通道，或者使用 `torch.complex64`），否则网络无法学习到相位特征。

## 二、 FFT (快速傅里叶变换)

### 1. 基础概念
- **时域与频域**：FFT将信号从时域（随时间变化的波形）变换到频域（包含哪些频率成分）。
- **计算效率**：离散傅里叶变换（DFT）的复杂度是 \(O(N^2)\)，而FFT利用对称性将其降为 \(O(N\log N)\)，这是数字信号处理的基石。

### 2. 在SAR项目中的应用
SAR成像的核心操作就是“匹配滤波”，而匹配滤波在频域中就是简单的乘法。
- **距离压缩**：沿距离向做FFT，乘以参考函数，再IFFT。
- **方位压缩**：沿方位向做同样的操作。
- **自聚焦**：相位误差通常在方位频域中进行估计和补偿。PAFnet/RAFnet这类网络，本质上是在学习如何更准确地估计频域中的相位误差，并通过可微的IFFT/FFT层来实现补偿。
- **PyTorch实现**：`torch.fft.fft()` 和 `torch.fft.ifft()` 是你们写自聚焦网络时的核心算子。

## 三、 张量 (Tensors)

### 1. 基础概念
张量是深度学习中多维数组的统称。
- 标量 (Scalar)：0维张量 (一个数)
- 向量 (Vector)：1维张量 (一列数)
- 矩阵 (Matrix)：2维张量 (二维表格)
- 高维张量：3维及以上 (如图像的 `[C, H, W]`)

### 2. 深度学习中的张量 (PyTorch)
在PyTorch中，`torch.Tensor` 是基本数据结构，支持GPU加速与自动求导。
- **常见维度**：`[Batch_Size, Channels, Height, Width]` (即BCHW格式)。
- **复数张量问题**：PyTorch原生不支持复数卷积。常见的做法是将复数数据拆分成实部和虚部两个通道（即 `Channels = 2`），或者使用 `torch.view_as_real()` 和 `torch.view_as_complex()` 进行转换。这一点在你们搭建PAFnet/RAFnet和SVNN时至关重要。
- **常用操作**：`reshape`（改变形状）、`permute`（交换维度）、`matmul`（矩阵乘法）、`to('cuda')`（放到GPU上）。

## 四、 三模块流程串联

结合以上基础，我们的三模块流程在代码层面是这样运作的：
1. **成像**：读取复数SLC -> 使用MATLAB/Python进行FFT和IFFT -> 输出复数图像。
2. **自聚焦**：输入散焦的复数图像（PyTorch张量，实部虚部双通道）-> 网络提取特征 -> 估计相位误差 -> 利用FFT进行相位补偿 -> 输出聚焦图像（与PGA方法对比）。
3. **旁瓣抑制**：输入聚焦后的复数图像 -> 空间变滤波网络（处理复数张量） -> 抑制旁瓣，保持主瓣 -> 输出恢复图像（与SVA方法对比）。
