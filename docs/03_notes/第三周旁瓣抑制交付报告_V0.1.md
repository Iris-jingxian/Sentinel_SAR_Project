# SVA 传统算法与评测 V0.1

基于 Sentinel_SAR_Project main 提交 183a33c。实际使用 MATLAB R2025a CPU 运行。

## 已完成

复数联合 I/Q、距离后方位顺序 SVA；原图/Hamming/SVA 三方法；同尺度图；双方向剖面；PSLR、固定门 ISLR、-3dB 宽度、峰值与主瓣能量保持率、相对输入相位 RMSE、单次耗时；复数 MAT、CSV、JSON 导出。

## 受控单点仿真结果

两个方向对称，下面列距离向；数值是原始采样剖面结果。

|方法|PSLR/dB|固定门 ISLR/dB|-3dB宽度/像素|峰值保持率|
|---|---:|---:|---:|---:|
|Original|-13.465|-10.002|1.6120|1.0000|
|Hamming|-18.925|-20.097|2.5634|1.0000|
|SVA|-319.564|-314.042|1.6120|1.0000|

理想无噪、整数过采样 sinc 下 SVA 可解析抵消旁瓣；极低 dB 是浮点残差，不代表真实场景可达到的抑制能力。主瓣宽度不展宽，峰值保持。Hamming 的固定门指标包含展宽溢出原主瓣门的能量。

## 验证

PASS: zero, scale/phase equivariance, attenuation, weight minimization, sinc sidelobe cancellation and peak preservation。五个场景共30条方法/方向记录；图像及剖面已导出。

## 真实 ROI 使用边界

三个 ROI 均运行，但有效带宽、频谱中心、既有加窗尚未核实，lag=[1,1] 仅探索性结果，不能作为真实 SVA 性能验收。真实剖面可能包含多个真实目标，PSLR/ISLR 是局部代理指标；相位误差相对输入，不代表真值。

实际 ROI 的 PSLR 在若干剖面上未改善；不能据此宣称真实数据已达到预期抑制效果，下一版应先核对采样与频谱假设。
