# B03｜旁瓣抑制 Week 1：选型与文献笔记

## 1. 任务结论

**选定方案：CNN + RSVA（Robust Spatially Variant Apodization）。**

RSVA 可在不显著牺牲空间分辨率的前提下抑制旁瓣，但在杂波目标附近可能造成主瓣能量损失。采用 CNN 对 RSVA 结果进行能量补偿，可将“旁瓣抑制”和“主瓣/SNR 保持”作为共同优化目标。

该组合与 B03 任务目标直接对应，且具备清晰的传统基线与可复现实验路径。

## 2. 文献笔记

### 核心文献

Yuan, S.; Yu, Z.; Li, C.; Wang, S. *A Novel SAR Sidelobe Suppression Method Based on CNN.* IEEE Geoscience and Remote Sensing Letters, 18(1), 132–136, 2021. DOI: [10.1109/LGRS.2020.2968336](https://doi.org/10.1109/LGRS.2020.2968336)

要点：

- 以 CNN 补偿 RSVA 在杂波目标上可能产生的能量损失；
- 将旁瓣抑制与目标能量保持联合处理；
- 文中报告：相较传统方法，该方法在旁瓣抑制指标及 SNR 保持方面表现更好。

### 补充背景

Li et al., 2018. DOI: [10.5194/isprs-archives-XLII-3-771-2018](https://doi.org/10.5194/isprs-archives-XLII-3-771-2018)

常规窗函数抑制旁瓣通常伴随分辨率损失。因此，评价中需同步关注 PSL/ISLR、主瓣保持率、分辨率与视觉保真度。

## 3. 输入与输出说明

### 输入

- `I0`：归一化 SAR 强度图；建议保留原始幅度/强度标定信息。
- `IRSVA`：对 `I0` 进行 RSVA 处理后的图像。
- 模型接口：以 `[I0, IRSVA]` 作为双通道张量输入。

若仅具备单通道数据，可先实现 `IRSVA` 单通道 CNN 基线，再扩展至双通道模型。

### 输出

- `Î`：旁瓣得到抑制、同时完成主瓣能量补偿的 SAR 强度图。
- 附带输出：推理参数、RSVA 参数、模型版本与评测记录，便于复现。

## 4. 验证与验收指标

| 指标 | 评价目的 | 建议评估对象 |
|---|---|---|
| PSL | 衡量峰值旁瓣水平 | 点目标剖面、强散射体邻域 |
| ISLR | 衡量积分旁瓣能量 | 点目标及典型目标窗口 |
| 主瓣峰值保持率 | 比较处理前后目标主瓣峰值变化 | 点目标、杂波背景中的强目标 |
| SNR | 检查能量补偿后的信噪保持 | 仿真与真实 SAR 场景 |
| 分辨率与视觉保真 | 检查主瓣展宽、细节与伪影 | 剖面图、局部放大图、完整场景 |

建议对 RSVA、CNN+RSVA 与传统窗函数在同一数据和评测窗口下进行联合比较。

## 5. 后续实验计划

1. 实现 RSVA 基线并记录参数；
2. 构建 CNN 补偿模型与训练/验证集划分；
3. 在仿真点目标和真实 SAR 场景上对比 RSVA、CNN+RSVA 与传统窗函数；
4. 汇总指标、可视化结果及失败案例。
