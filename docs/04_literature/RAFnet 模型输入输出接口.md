RAFnet 模型输入输出接口说明书

 

**1. 模型概览**

- 模型名称：RAFnet (Range-aware Autofocus Network)

- 任务类型：SAR图像自聚焦（方位向相位误差估计）

- 核心机制：渐进式三级聚焦单元，逐级校正不同阶数相位误差

 

**2. 输入接口定义**

- 输入名称：`defocused_sar_image`

- 数据维度：`(B, 2, 256, 256)`（B为批次大小）

- 数据类型：Float32

- 通道说明：Channel 0 = 复数实部，Channel 1 = 复数虚部

- 预处理：原始复值SAR图像拆分为实部/虚部双通道

 

**3. 输出接口定义**

- 输出名称：`phase_error_coefficients`（分级输出）

- 第1级输出：`(B, 2)` — 2阶、3阶相位误差系数

- 第2级输出：`(B, 2)` — 4阶、5阶相位误差系数

- 第3级输出：`(B, 2)` — 6阶、7阶相位误差系数

- 物理意义：多项式相位误差系数（α向量），用于生成相位误差补偿向量

 

**4. 后处理流程**

1. 将各级输出的系数代入多项式相位误差模型

2. 生成完整的相位误差向量φ(k)

3. 在距离多普勒域对原始图像进行补偿

4. 输出聚焦后的SAR图像
