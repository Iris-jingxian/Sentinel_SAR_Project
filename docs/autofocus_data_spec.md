# 自聚焦模块：数据规格与接口说明 (V1)

本项目针对 SAR 图像自聚焦任务，采用“**仿真注入 + 场景隔离**”的数据构建策略。

## 1. 数据集与场景划分（防泄露）

为了保证模型评估的客观性，我们采用**严格的按场景划分（Scene-level Split）**，防止同一场景的切块同时出现在训练集和测试集中，避免数据泄露。

具体的划分清单由 `data/splits/autofocus_split_v1.json` 固定管理：

| 场景名称 (Scene ID) | 来源原图 | 数据用途 | 样本数量 | 散焦强度 |
| :--- | :--- | :--- | :--- | :--- |
| `sim_phase_ROI_1_complex` | 强反射区 (ROI_1) | **Train (训练)** | 100 | 弱/中/强 混合 |
| `sim_phase_ROI_2_complex` | 均匀弱目标区 (ROI_2) | **Val (验证)** | 100 | 弱/中/强 混合 |
| `sim_phase_ROI_3_complex` | 复杂边缘区 (ROI_3) | **Test (独立测试)** | 100 | 弱/中/强 混合 |

## 2. 数据清单 (Manifest)

各个场景的样本详细清单存储在对应输出目录的 `manifest.csv` 中。
清单包含的字段：
- `sample_id`: 样本唯一标识符
- `scene_id`: 样本所属场景，用于划分检查
- `input_path`: 网络输入（散焦复图像）的本地路径
- `label_path`: 网络标签（相位误差系数）的本地路径
- `defocus_strength`: 注入的散焦强度（weak / medium / strong）

## 3. 网络输入与标签核对 (标签接口)

我们严格核对了 RAFnet 网络模型与 Dataset 之间的数据接口：

### 3.1 网络输入 (Input)
- **格式**：双通道复数张量。
- **维度**：`(Batch, 2, 512, 512)`。
- **通道说明**：Channel 0 为复图像的实部，Channel 1 为复图像的虚部。
- **处理方式**：保留了完整的相位信息，不进行 `abs()` 幅度提取；在 Dataset 中按样本最大幅度进行归一化，保留原始相位分布。

### 3.2 标签 (Label)
- **格式**：一维向量。
- **维度**：`(Batch, 6)`。
- **物理意义**：多项式相位误差模型 \(\phi(f) = \sum_{k=2}^{7} \alpha_k (2\pi f)^k\) 中的 6 个系数（\(\alpha_2\) 到 \(\alpha_7\)）。
- **生成方式**：在频率域向原始清晰图像注入已知的多项式相位误差 \(\exp(j\phi)\)，保存生成的 \(\alpha\) 向量作为网络回归目标。

## 4. 评估指标
在测试集上，我们不仅输出预测系数与真实系数的 MSE Loss，还通过逆向相位补偿，对比了：
- 图像熵 (Entropy)
- 图像对比度 (Contrast)
- 主瓣展宽与边缘恢复情况 (视觉验证)

详细结果记录在 `data/evaluation_results.csv` 中。
从最终补偿效果来看，RAFnet 在未见过测试场景下成功抑制了方位向散焦，恢复了一定边缘纹理
