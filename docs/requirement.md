# 哨兵SAR图像处理软件需求清单（V0.1）

> 本项目面向哨兵SAR成像、自聚焦与旁瓣抑制，开发支持算法运行、结果对比与指标计算的图像处理软件。

## 一、 数据导入与准备模块
- [ ] 支持导入仿真回波数据（SM条带模式）。
- [ ] 支持读取真实的 Sentinel-1 SM SLC 复数数据。
- [ ] 能够提取并保存产品参数（产品标识、成像模式、极化方式、采样信息、距离与方位轴、像素间隔等）。
- [ ] 数据异常时能给出提示或报错。
- [ ] （可选）支持读取GRD数据用于浏览参考。

## 二、 核心算法模块（支持传统与深度学习切换）
### 2.1 SAR成像模块
- [ ] 实现距离多普勒（RD）算法（包含距离压缩、距离徙动校正、方位压缩），输出复数图像与剖面。

### 2.2 自聚焦模块
- [ ] 传统方法：实现 PGA 算法。
- [ ] 深度学习方法：实现 PAFnet 或 RAFnet 网络。
- [ ] 支持散焦样本注入与网络推理。

### 2.3 旁瓣抑制模块
- [ ] 传统方法：实现 SVA 算法。
- [ ] 深度学习方法：实现 SVNN 或 CNN+RSVA 网络。
- [ ] 支持模型权重的加载与切换。

## 三、 结果对比与展示模块
- [ ] 显示原始回波、距离压缩结果、最终复数图像（统一采用幅度对数尺度显示）。
- [ ] 显示距离向和方位向的剖面图。
- [ ] 自聚焦模块需显示相位误差曲线。
- [ ] 支持同尺度输入与输出对比（如：未补偿 vs PGA vs 网络自聚焦；原图 vs SVA vs 网络旁瓣抑制）。

## 四、 指标计算与评估模块
- [ ] **自聚焦指标**：计算幅度NRMSE（归一化均方根误差）、图像熵、图像对比度、主瓣宽度、推理耗时。
- [ ] **旁瓣抑制指标**：计算距离向/方位向的 PSLR（峰值旁瓣比）、ISLR（积分旁瓣比）、-3dB主瓣宽度、峰值幅度、相位误差。
- [ ] **弱目标检查**：检查弱目标是否保留、是否产生新的虚假峰。
- [ ] 指标结果保存为CSV格式。

## 五、 导出与软件交互模块
- [ ] 复数结果保存为 `.mat` 文件。
- [ ] 预览图保存为 `.png` 文件。
- [ ] 参数及处理链保存为 `.json` 文件。
- [ ] 使用 Streamlit 搭建界面，通过 MATLAB Engine for Python 调用传统算法。
- [ ] 提供 Windows 启动脚本，支持离线运行。
- [ ] 支持算法独立运行或串联处理（成像 -> 自聚焦 -> 旁瓣抑制）。
- [ ] 错误输入提示（如缺失权重、不兼容的输入）。
